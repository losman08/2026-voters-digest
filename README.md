# Ballot Cliffnotes

A non-partisan, plain-language voter guide. It explains ballot measures and candidates in clear terms — what each does, what a Yes/No vote means, who's for and against, the official full legal text, and how each measure could affect you based on your situation — so people can vote with confidence instead of wading through legalese.

- **Non-partisan.** Sourced from official state voter guides and non-partisan newsrooms. It does not tell anyone how to vote.
- **Multi-state.** California is live; more states roll out before Election Day.
- **Free to share.** Single static page, no login, no tracking.

Sources per measure: the state's official voter guide (full legal text as written by lawmakers) and non-partisan coverage. Candidate controversies are labeled by how well they're verified; nothing is invented.

Built for family and friends.
